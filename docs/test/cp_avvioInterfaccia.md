# cp_avvioInterfaccia

Specifica dei casi di test (category partition) della logica dell'avvio della sosta nell'interfaccia: funzioni pure di `src/presentation/logica/avvioSosta.ts` e, dalla OMP-61, di `src/presentation/logica/permesso.ts` (passaggio del permesso negli stalli riservati), usate dalla scheda dello stallo del boundary `:MappaStalli` (`MU_2`).
Requisiti: RF_SOSTA_1 (avvio della sosta), RF_WALLET_2 (addebito, credito insufficiente), NRF_USA_2 (avvio e pagamento in tre interazioni), RF_SOSTA_5 (dichiarazione e foto del permesso sugli stalli riservati), RF_STALLI_2 (tariffe e condizioni dello stallo nella scheda, dalla COD-23). Task OMP-58 (issue #29); dalla OMP-61 (issue #33, blocco B) avvio sugli stalli riservati con il passaggio del permesso, TF-AVVUI-02 e 03 aggiornati e TF-AVVUI-31…57 aggiunti; dalla OMP-64 (COD-23, issue #44) TF-AVVUI-58…60.

- **Fonti dell'esito atteso:** `UC_SOSTA_1` (entry condition: stallo `Occupato`; passi 1–5; flussi 2.a1, 2.a2, 2.a3, 2.a4, 5.a1), `SD_SOSTA_1`, `np_01_automobilista` (Scheda → ErrCredito → Ricarica → «torna alla conferma»), `cp_apiWalletSoste.md` §2 (codici di errore di `POST /api/soste`), `cp_calcoloImporto.md` §2 (durata intera da 15 minuti alla durata massima), issue #29 (categorie minime: stato dello stallo → disponibilità di «Avvia sosta»; tipo di stallo; credito rispetto all'importo), piano approvato di OMP-58 (punti 4 e 6, decisioni D2 e D4); dalla OMP-61: `np_01_automobilista` (Scheda → «Dichiarazione e foto del permesso» [stallo riservato] → «permesso dichiarato»), `UC_SOSTA_5` (passi 1–3, flusso 2.a1), scenari `SC_UT_3` e `SC_UT_6`, `cp_avvioSosta.md` §2 (regola del permesso nel servizio), `cp_apiWalletSoste.md` §2 (JSON o `multipart/form-data`), issue #33 (foto scattata dalla fotocamera o scelta dalla galleria, JPEG o PNG, al massimo 2 MB) e piano approvato di OMP-61 (decisioni D5: riduzione della foto nel browser, lato massimo 1600 px, JPEG; D6: due input).
- **File di test:** `src/presentation/logica/avvioSosta.test.ts` (funzioni di `avvioSosta.ts`) e `src/presentation/logica/permesso.test.ts` (funzioni di `permesso.ts`), eseguiti da `npm test` (ambiente node, senza database).

## 1. Tracciabilità

Ogni frame riporta un solo riferimento, scelto in quest'ordine: un requisito dell'Elenco (`RF_…`, `NRF_…`) se il suo testo copre davvero il comportamento; altrimenti il vincolo di dominio `VD_<n>`; altrimenti `ISSUE_29` o `ISSUE_33` per le scelte delle issue #29 e #33 e dei piani approvati di OMP-58 e OMP-61.

Nome del test: `<riferimento> · <frame> · <descrizione> → <esito>`, per esempio `RF_SOSTA_1 · TF-AVVUI-04 · stallo Libero → non disponibile con il motivo`.

## 2. Funzioni verificate (firme)

```ts
// src/presentation/logica/avvioSosta.ts — nessuna dipendenza da React né dai sottosistemi
type Disponibilita = { disponibile: true } | { disponibile: false; motivo: string };
disponibilitaAvvio(stato: string, tipoDiStallo: string): Disponibilita;
opzioniDurata(durataMassima: number): number[];        // minuti
durataPredefinita(durataMassima: number): number | null;
etichettaDurata(minuti: number): string;
creditoSufficiente(saldo: number, importo: number): boolean; // centesimi
etichettaConferma(importo: number): string;            // testo del pulsante dell'interazione 3
const CAMPI_AVVIO_SOSTA: Readonly<Record<string, string>>; // codice → campo, per interpretaRisposta (cp_risposteApi.md)
type PermessoDiAvvio = { dichiarazione: string; foto: Blob };       // dalla OMP-61
richiestaDiAvvio(dati: { stallo: number; targa: string; durata: number; permesso?: PermessoDiAvvio }): RequestInit; // POST /api/soste
type TariffaDelloStallo = { costoOrario: number; orarioInizioVigenza: string; orarioFineVigenza: string; durataMassima: number }; // da GET /api/stalli/<id>
condizioniDelloStallo(tipoDiStallo: string, tariffa: TariffaDelloStallo): { tariffa: string; durataMassima: string; permesso: string | null }; // dalla COD-23

// src/presentation/logica/permesso.ts (OMP-61) — nessuna dipendenza da React, dal DOM né dai sottosistemi
richiedePermesso(tipoDiStallo: string): boolean;
testoDichiarazione(tipoDiStallo: string): string | null;
const FOTO_MASSIMA: number;            // 2 097 152 byte, come il servizio
const LATO_MASSIMO: number;            // 1600 px (decisione D5)
verificaFotoPermesso(foto: { tipo: string; dimensione: number }): string | null; // messaggio d'errore o null
dimensioniRidotte(larghezza: number, altezza: number): { larghezza: number; altezza: number };
```

**`disponibilitaAvvio`**, regole in quest'ordine (prima lo stato, poi il tipo):

| Caso                                                          | Esito                                                                                                                            |
| :------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------- |
| stato `LIBERO`                                                | `{ disponibile: false, motivo: "Lo stallo risulta libero: la sosta si avvia quando il sensore rileva il veicolo." }`             |
| stato `NON_DISPONIBILE`                                       | `{ disponibile: false, motivo: "Sullo stallo c'è già una sosta in corso." }`                                                     |
| stato `SCONOSCIUTO`                                           | `{ disponibile: false, motivo: "Lo stato dello stallo non è affidabile: la sosta non si può avviare." }`                         |
| altro stato diverso da `OCCUPATO`                             | `{ disponibile: false, motivo: "La sosta non si può avviare su questo stallo." }`                                                |
| `OCCUPATO`, tipo `ORDINARIO_A_PAGAMENTO`, `DISABILI` o `ROSA` | `{ disponibile: true }`; su `DISABILI` e `ROSA` «Avvia sosta» porta al passaggio del permesso (`richiedePermesso`, dalla OMP-61) |
| `OCCUPATO`, altro tipo                                        | `{ disponibile: false, motivo: "La sosta non si può avviare su questo stallo." }`                                                |

**Durata:** `opzioniDurata` restituisce i multipli di 15 da 15 a `durataMassima`, in ordine crescente; se `durataMassima` non è multiplo di 15 la aggiunge come ultima opzione; con `durataMassima` < 15 restituisce `[]`. `durataPredefinita` è 60 se `durataMassima` ≥ 60, altrimenti `durataMassima` se ≥ 15, altrimenti `null`. `etichettaDurata`: `"<m> min"` sotto l'ora, `"<h> h"` per ore intere, `"<h> h <m> min"` altrimenti.

**Credito:** `creditoSufficiente` è `saldo >= importo`.

**Conferma:** `etichettaConferma(importo)` = `"Conferma e paga (" + formattaEuro(importo) + ")"` (`cp_formatoImporti.md`) se l'importo è maggiore di 0; con importo 0 (sosta `GRATUITA` sugli stalli per disabili, dalla OMP-61) `"Conferma (senza addebito)"`. La stessa etichetta serve alla conferma del prolungamento (`cp_prolungamentoInterfaccia.md`).

**`CAMPI_AVVIO_SOSTA`:** `CREDITO_INSUFFICIENTE` → `"credito"` (proposta di ricarica); `DURATA_NON_VALIDA` → `"durata"`; `TARGA_NON_NEL_PROFILO` e `SOSTA_GIA_ATTIVA` → `"targa"`; dalla OMP-61 `PERMESSO_MANCANTE` e `PERMESSO_NON_VALIDO` → `"permesso"` (il passaggio del permesso resta aperto con il messaggio, `UC_SOSTA_5` 2.a1); ogni altro codice, compreso `PERMESSO_NON_PREVISTO`, va su `"generale"` (regola 3 di `cp_risposteApi.md`). Si verifica attraverso `interpretaRisposta(status, corpo, CAMPI_AVVIO_SOSTA)`.

**`richiestaDiAvvio`** (dalla OMP-61, `cp_apiWalletSoste.md` §2):

- senza `permesso`: `{ method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify({ stallo, targa, durata }) }`, come in OMP-58;
- con `permesso`: `{ method: "POST", body }` senza intestazione `content-type` (la imposta il browser con il separatore), dove `body` è un `FormData` con i campi di testo `stallo`, `targa`, `durata` (numeri scritti in cifre), `dichiarazioneDiPermesso` (`permesso.dichiarazione`) e il file `fotoDelPermesso` con il contenuto di `permesso.foto` e nome `permesso.png` se il tipo della foto è `image/png`, altrimenti `permesso.jpg`.

**`condizioniDelloStallo`** (dalla COD-23, `UC_STALLI_2` passo 2 e flusso 2.a1): i testi delle righe «Tariffa», «Durata massima» e «Permesso» della scheda, mostrati prima di «Avvia sosta».

- `tariffa`: `formattaEuro(costoOrario) + " l'ora, dalle " + HH:MM di inizio + " alle " + HH:MM di fine` (gli orari arrivano come `HH:MM:SS`); per `DISABILI` lo stesso testo è preceduto da `"Sosta gratuita con il contrassegno esposto · tariffa dello stallo "`: prima la gratuità (RD_06), poi costo orario e fascia, che restano (`UC_STALLI_2` passo 2);
- `durataMassima`: `etichettaDurata(durataMassima)`;
- `permesso`: `DISABILI` → `"Contrassegno di parcheggio, da dichiarare e fotografare all'avvio della sosta."` (la gratuità è già nella riga «Tariffa»); `ROSA` → `"Permesso rosa, da dichiarare e fotografare all'avvio; sosta a pagamento."`; ogni altro tipo → `null` (la riga non compare).

**`richiedePermesso`:** `true` per `DISABILI` e `ROSA`, `false` per ogni altro tipo (RF_SOSTA_5, VD_8).

**`testoDichiarazione`** (la dichiarazione mostrata accanto alla casella e inviata come `dichiarazioneDiPermesso`, RF_SOSTA_5: «la dichiarazione di esporre il permesso previsto per quel tipo di stallo»):

| Tipo di stallo  | Testo                                                                           |
| :-------------- | :------------------------------------------------------------------------------ |
| `DISABILI`      | `"Dichiaro di esporre sul veicolo il contrassegno per persone con disabilità."` |
| `ROSA`          | `"Dichiaro di esporre sul veicolo il permesso rosa."`                           |
| ogni altro tipo | `null`                                                                          |

**`verificaFotoPermesso`** (controllo anticipato nel browser, sulla foto già ridotta; il server resta l'autorità e riconosce il formato dai primi byte, `cp_avvioSosta.md` §2), regole in quest'ordine:

1. `dimensione` 0 → `"Scatta o scegli la foto del permesso esposto."`;
2. `tipo` diverso da `image/jpeg` e da `image/png` → `"La foto deve essere un'immagine JPEG o PNG."`;
3. `dimensione` maggiore di `FOTO_MASSIMA` (2 097 152) → `"La foto supera 2 MB: scegline una più leggera."`;
4. altrimenti `null`.

**`dimensioniRidotte`** (decisione D5): se il lato maggiore supera `LATO_MASSIMO` (1600), entrambi i lati sono moltiplicati per `1600 / lato maggiore` e arrotondati all'intero più vicino (il lato maggiore diventa esattamente 1600); altrimenti le dimensioni restano quelle date (mai ingrandite). La riduzione con il canvas e la codifica JPEG (qualità 0,85) sono del componente `PermessoStallo.tsx` e si verificano a mano e con TS-14.

## 3. Ambiente

Funzioni pure: nessun database, nessuna rete, nessun DOM. `Blob` e `FormData` sono quelli di Node (globali dalla versione 18), senza DOM. `<msg>` indica il messaggio del frame, restituito invariato. Foto di prova per `richiestaDiAvvio`: `new Blob([new Uint8Array([0xff, 0xd8, 0xff, 0xe0])], { type: "image/jpeg" })` (`J`) e `new Blob([new Uint8Array([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a])], { type: "image/png" })` (`P`); `D` = `"Dichiaro di esporre sul veicolo il permesso rosa."`. Lo spazio indivisibile prima di `€` è scritto ` `.

## 4. Categorie e scelte

**Stato dello stallo:** Occupato · Libero [error] · Non disponibile [error] · Sconosciuto [error] · non riconosciuto [error].

**Tipo di stallo:** a pagamento · rosa → passaggio del permesso · per persone con disabilità → passaggio del permesso · non riconosciuto [error].

**Durata massima:** multiplo di 15 · non multiplo di 15 [single] · inferiore a 15 [error].

**Credito rispetto all'importo:** sufficiente · uguale [single] · insufficiente [error] → proposta di ricarica · importo zero.

**Esito dell'avvio:** avviata · credito insufficiente [error] · durata non valida [error] · targa non del profilo [error] · sosta già attiva per la targa [error] · stallo non più occupato [error] · sessione scaduta [error] · permesso mancante [error] · permesso non valido [error] · permesso non previsto [error].

**Importo nel pulsante di conferma:** maggiore di 0 · zero (sosta gratuita) [single].

**Corpo della richiesta di avvio** (dalla OMP-61): senza permesso → JSON · con permesso e foto JPEG → multipart · con permesso e foto PNG → multipart [single].

**Dichiarazione per tipo di stallo:** per persone con disabilità · rosa · a pagamento → nessuna.

**Foto del permesso (controllo anticipato):** JPEG entro il limite · PNG entro il limite · esattamente 2 MB [single] · vuota [error] · altro formato [error] (HEIC, GIF) · oltre 2 MB [error] · più errori insieme [single] → vale il primo.

**Condizioni nella scheda** (dalla COD-23): stallo a pagamento → nessun permesso · per persone con disabilità → sosta gratuita con il contrassegno, tariffa dello stallo e contrassegno da dichiarare · rosa → permesso e sosta a pagamento.

**Dimensioni della foto:** orizzontale oltre 1600 · verticale oltre 1600 · lato maggiore uguale a 1600 [single] · entro il limite → invariate · proporzioni estreme [single].
